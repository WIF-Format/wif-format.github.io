Future Ideas and Proposals

Developers agree that change is needed, but have different approaches to how that should be done. Some thoughts are that it should be completely re-designed and some are more evolutionary. This page provides a place that these proposals can be presented.

Developer Communication

Websites are fairly static, so we need a place that we can share thoughts and ideas and address current proposals. The best place for that is social platform like Facebook or message group list group.io. We need an admin to volunteer for the establishment of such a site and the monitoring of it.

Personal Thoughts

I, Sally Breckenridge, created this website and registered the domain name as Wif needs a more formal organization for the future. I participated in the original draft discussions, and it's truly amazing that a group of developers agreed and shared this specification. Patternland application on Windows no longer exists but Ravi Nielsen made a wonderful gift to the weaving world by promoting and leading this activity. We all benefit from it.

At this phase of my life, I cannot be the be the promoter. We need someone with more energy and enthusiasm. I will happily turn over the domain name and website maintenance to willing promoter of the Wif Format.
