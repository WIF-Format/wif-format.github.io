Future Ideas and Proposals

Developers agree that change is needed, but have different approaches to how that should be done. Some thoughts are that it should be completely re-designed and some are more evolutionary. This page provides a place that these proposals can be presented.

Two proposals for the next version of WIF are written up on the developer site, so that everyone can read them and comment:

WIF 1.2: a small update. Files stay plain text with the .wif extension, and every WIF 1.1 file is also a valid WIF 1.2 file.

WIF 2: a larger redesign. Drafts are stored in JSON, a common text format that programs read easily, in a new .wif2 file.

Nothing in either proposal is decided. Each one is discussed on a pull request: a page on GitHub that shows a proposed change and has a place to comment. The Proposals under discussion page explains how to comment, or you can email the contact address below.

Developer Communication

Websites are fairly static, so we need a place that we can share thoughts and ideas and address current proposals. Developers and weavers usually look in different places, so there are two.

For developers of weaving software, the place is the WIF-Format organization on GitHub, where the WIF guides and proposals are kept. Each proposal is discussed on its pull request, a page that shows the proposed change and has a place to comment, and the discussion stays there for anyone to read later. The Proposals under discussion page explains how to comment.

For weavers, news about WIF, and about which apps support it, is best shared where weavers already meet: weaving groups on Facebook, and email lists such as WeaveTech and the other groups on Groups.io. We need volunteers to share news and updates there, and to point developers to GitHub.

Personal Thoughts

I, Sally Breckenridge, created this website and registered the domain name as Wif needs a more formal organization for the future. I participated in the original draft discussions, and it's truly amazing that a group of developers agreed and shared this specification. Patternland application on Windows no longer exists but Ravi Nielsen made a wonderful gift to the weaving world by promoting and leading this activity. We all benefit from it.

At this phase of my life, I cannot be the be the promoter. We need someone with more energy and enthusiasm. I will happily turn over the domain name and website maintenance to willing promoter of the Wif Format.
